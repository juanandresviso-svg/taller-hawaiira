# Taller Hawaiira

App de control del taller de Hawaiira Studio: pedidos, producción por estación, alertas de entrega, cuellos de botella y recomendaciones de expansión.

Stack: Next.js · Supabase · Vercel · Gmail del taller (invitaciones y resumen diario). Sin dominio propio: usa la dirección gratuita de Vercel. Instalable como app de escritorio (PWA).

La guía para publicarla está en [INSTRUCTIVO.md](./INSTRUCTIVO.md) y el manual del equipo en [MANUAL-DE-USO.md](./MANUAL-DE-USO.md).
