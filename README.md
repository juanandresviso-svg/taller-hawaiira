# Taller Hawaiira

App de control del taller de Hawaiira Studio: pedidos, producción por estación, alertas de entrega, cuellos de botella y recomendaciones de expansión.

Stack: Next.js · Supabase · Vercel · Resend (accesos) · Brevo (resumen diario). Instalable como app de escritorio (PWA).

La guía completa para publicarla está en [INSTRUCTIVO.md](./INSTRUCTIVO.md).
